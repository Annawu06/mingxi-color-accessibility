# 色彩处理边界

明晰的四个模式是用户可自行比较的视觉调整预设，不是色觉缺陷模拟，也不是经临床验证的 daltonization 算法。模式名称表示设计目标，不表示对用户色觉类型的判断。

页面整体和单独增强的图片、视频、Canvas 使用同一组 CSS `filter` 预设与强度参数。同一元素只应用一层预设滤镜。Canvas 不读取或回写页面像素。非颜色提示（状态符号、链接下划线、图表纹理）独立于滤镜。

文字对比度使用 WCAG 2.1 的相对亮度和对比度公式。透明纯色背景按 Alpha 合成；背景图片、渐变、混合模式和透明元素会标记为无法可靠判断，不自动修正。

SVG 图表只在数据图形明确带有 `data-series`、`data-series-id`，或位于明确标注系列的 `<g>` 中，且至少存在两个系列时，添加纹理和线型。无法识别系列的 SVG 保持原状。新增节点与样式变化的复杂图表仍需在真实站点验证。

要证明预设能提升辨识准确率，需要标准色卡和真实色觉差异用户实验；现有测试只验证计算、设置和页面恢复行为。
