# Store Listing (English)

## Summary

Mingxi helps people with color vision deficiency understand web content more clearly. It offers optional color assistance, contrast enhancement, text and icon cues, chart patterns, underlined links, and a distraction-free reading mode.

## Features

- Per-site visual modes and intensity settings
- Red, green, and blue-yellow color assistance
- Automatic improvement for selected low-contrast text
- Non-color cues for success, warning, error, and required fields
- Enhancement for images, Canvas, SVG, and video
- Color probe, site exclusion, keyboard shortcuts, and local feedback controls

## Privacy

Preferences use browser sync storage and may sync across devices when browser sync is enabled. Feedback and usage counts stay local. Mingxi does not upload page content or call an AI service by default.

## Important note

Mingxi is an accessibility aid, not a medical diagnostic or treatment tool. The color-pattern demo is not a standardized test and has no medical screening validity.
