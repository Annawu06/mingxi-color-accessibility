# Mingxi 明晰 · 色彩无障碍

[English README](README_EN.md)

[隐私政策](PRIVACY.md) · [中文商店介绍](STORE_LISTING_ZH.md)

帮助色盲和色弱用户更容易理解网页信息。

## 功能

- 可选的颜色重映射辅助层
- 自动提高文字与背景对比度
- 按网站调节网页字体大小
- 为成功、警告和错误状态增加文字与图标提示
- 为链接增加下划线，并增强图表和图片
- 按网站保存设置并支持强度调节
- 非医疗性质的色觉初步筛查体验
- 快捷键：`Alt + Shift + S` 开关模式，`Alt + Shift + R` 打开阅读模式

## 免责声明

明晰是无障碍辅助工具，不是医学诊断或治疗工具。当前色觉测试仅用于非医疗筛查。

## 本地安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `extension/` 文件夹。
